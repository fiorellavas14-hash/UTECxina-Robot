# 🤖 UTECxina | Interactive Robotic Assistant

**UTECxina** es un proyecto de robótica e inteligencia artificial desarrollado para mejorar la experiencia de orientación e interacción dentro de entornos universitarios.

El proyecto busca facilitar el acceso a información mediante un asistente físico inteligente, capaz de interactuar con los usuarios, interpretar consultas y proporcionar respuestas de manera intuitiva.

## 🎯 Objetivo

Desarrollar un asistente robótico interactivo que combine software y hardware para ofrecer una experiencia de comunicación accesible, dinámica y eficiente.

## ✨ Características principales

- Interacción mediante comandos de voz.
- Procesamiento de consultas y generación de respuestas.
- Integración entre software y componentes electrónicos.
- Detección e interacción con el entorno.
- Comunicación mediante respuestas auditivas y visuales.
- Arquitectura modular que permite incorporar nuevas funcionalidades.

## 🛠️ Tecnologías utilizadas

- **Python:** procesamiento de consultas, lógica e interacción por voz.
- **ESP32:** control y comunicación con componentes electrónicos.
- **C++ / Arduino IDE:** programación del microcontrolador.
- **Wokwi:** simulación y pruebas del circuito electrónico.
- **Visual Studio Code:** desarrollo e integración del software.

## 🚀 Estado del proyecto

**En desarrollo | Prototipo funcional en fase de integración y pruebas.**

UTECxina continúa evolucionando con el objetivo de mejorar sus capacidades de interacción, integración y funcionamiento autónomo.
